2026-11-15 · 정윤 4→3 보정 + 6단계 보정 통합 검증

**두 기능을 통합했고 기존 제출 3,451개 예측과 모두 일치한다. E16을 포함한 전체 자료를 주 평가로 사용한다. 리더보드 점수를 입력하거나 모델·임계값 선택에 사용하지 않았다.**

실행 코드는 [build_combined.py](build_combined.py), 통합 제출은 [submission_jeongyun43_stage6.csv](combined_v2/submission_jeongyun43_stage6.csv), 실행 근거는 [manifest.json](combined_v2/manifest.json)이다. 같은 폴더에 생성한 `combined.joblib`은 Git에서 제외한다.

검증 기준과 방법

- **주 평가:** 공식 train 78실험 + validation 19실험의 **97실험·43,722행 전체**, 실험 단위 5-fold. E16 1,543행 전부 포함. 누락·제외 실험은 없다. E16은 첫 바깥 fold의 평가 실험이며 해당 fold를 예측하는 기본 모델·정규화·체크포인트 선택·보정 모델 학습에서 모두 제외했다.
- 새 기본 모델 **60개를 15 epoch씩, 총 900 epoch 학습**했다. 바깥 fold마다 내부 그룹 제외 모델 3묶음과 바깥 학습 전체 모델 1묶음이 있고, 각각 seed 42·43·44를 사용한다. 보정 학습 확률도 바깥 학습 자료 안에서 실험을 분리해 생성했다.
- 학습 manifest, 확률·가중치 해시, 최고 epoch를 감사하고 각 모델의 결측값 대체·정규화 값을 실제 학습 행에서 다시 계산했다. 기존 78실험 5-fold와 77실험 2회×5-fold는 보조 검증으로 재실행한다. 이전 77실험에는 E16이 없으므로 이를 전체 자료의 주 검증으로 취급하지 않는다.
- **제출 가중치 별도 평가:** 공식 validation 19실험·10,200행 전부, E16 포함. E16 제외 점수는 새 평가에서 계산하지 않는다.
- 구조와 임계값은 고정했다: B 3-seed 평균 → T1 누적 45℃ 규칙 → 5→6(0.7) → 6→5(0.7) → **정윤 4→3(0.5)** → **S3 합계 정점(H=300, d=5, 관측된 전압 하강 조건)**. 4→5와 3→4는 꺼져 있다. 추가 탐색·선택은 하지 않았다.
- [고정 프로토콜](protocol_v2.json), [새 학습 영수증](combined_v2/fresh_training_receipt.json).

E16에서 남는 문제

- **E16을 학습·선택에서 완전히 제외한 새 OOF:** S3로 6단계 미검출 **12→1개**, 오탐 **2→3개**, 6단계 F1 **0.5625→0.9091**. 14개를 고치고 원래 맞은 1개를 틀리게 바꿨다. 전체 단계 오류는 여전히 **1,017/1,543행** 남는다.
- **기존 제출 가중치:** E16의 6단계 미검출 **20→3개**, 오탐 **0→3개**. 전체 오류는 **826→809행**으로 줄었으나 실제 5를 4로 예측한 **539행**, 실제 3을 2로 예측한 **222행** 등이 남는다. [혼동 내역](combined_v2/E16_residuals.json).
- E16을 위한 별도 ID 규칙, 전환시각·정답을 추론에 넣지 않았다. 모든 실험에 같은 코드를 적용했다. 일부 6단계 오류 감소가 전체 단계 문제의 해결을 뜻하지 않는다.

판정과 한계

**요청한 결합은 기존 제출을 정확히 재현했으며, E16을 포함한 독립 검증에서도 전체 F1과 6단계 오탐·미검출이 개선됐다.** 전체 모델의 편차는 남는다. 97실험 OOF 전체 F1의 실험 bootstrap 95% 구간은 **[0.77827, 0.90856]**이며 실제 비공개 테스트 점수 구간으로 해석하지 않는다.

공식 train·validation은 이전에도 살펴본 자료다. 과거 확인용 20실험도 이번에는 전체 CV에 포함했으므로 새로운 맹검 확인이라고 부르지 않는다. 기존 하위 artifact에는 전체 학습 실험 manifest가 없어 과거 가중치 계보를 완전히 증명하지 못하며, 독립 OOF는 새로 적합한 보정 모델을 사용한다. 리더보드 점수와 무관하게 E16의 남은 오류와 검증의 불확실성을 판단에 포함한다.
