# 미래 관측 참조 제거

대회 규칙에 따라 시각 t의 예측은 같은 실험에서 t까지 실제 관측한 값만 사용한다. 예측 영향 여부와 관계없이 위반 코드를 제거한다.

## 수정

- `final_rules3.py`: 초기 전압 기준을 관측 도착 시점에 갱신하는 순차 처리로 변경했다. 초기 5개 관측 동안 현재까지 확인한 최대 전압만 쓰고 이후 기준을 고정한다. 뒤에 들어올 값을 초기 행에 소급 적용하지 않는다.
- `temporal45_model/causal_rules.py`: 수정한 생산용 규칙을 공유한다. 별도의 옛 전압 기준 구현을 두지 않는다.
- `temporal45_model/audit_submission_causality.py`: 옛 미래 참조를 복원하는 실행 경로를 제거했다. 현재·과거 구현으로 기존 제출이 재현되는지만 확인한다.
- `temporal45_model/predict_conservative.py`: 외부의 보정된 예측을 그대로 받지 않고, 고정한 학습 임계값과 현재·과거 규칙으로 기준 예측을 계산한다.
- 루트 `AGENTS.md`: 미래 행, 뒤 채움, 음수 shift, 중심 이동창, 양방향 시계열 처리, 종료시각·전체 길이·평가 실험 전체 통계의 추론 사용을 금지하고 prefix 불변성 검증을 필수로 했다.

## 기존 제출 재생성

수정한 `final_rules3.py`로 제출을 다시 생성하고 `final_submit/submission_rules3.csv`에 반영했다. 3,451행과 전체 파일 내용이 기존 파일과 동일하다. 이 사실을 금지된 구현을 유지할 근거로 삼지 않았으며 원본 생성 코드를 수정했다.

SHA256: `bbbd60fac168aee9cba3b7041b45d9ba7f35093ddf6741db747e62bda7f11125`.

`submission_rules3_regeneration.json`에 재생성 결과가 있다. Test에는 정답이 없으며, 재생성과 불변성 검증에만 관측을 사용했다. 모델 학습이나 보정 기준 선택에 사용하지 않았다.

## 검증

- 관련 단위·통합 검증 16개 통과. 초기 전압 규칙을 포함해 실험을 중간에서 잘라도 이전 예측이 같음을 확인한다. 뒤에 큰 전압이 들어오는 합성 사례도 포함한다.
- 실제 Train 78개, Validation 19개, Test 11개 실험에서 756개 prefix를 확인했다. 각 시점까지 자른 입력의 온도 누적 최대·초기 전압 기준·전압 하락 상태가 전체 입력으로 계산한 같은 시점의 값과 일치했다. 결과는 `rules_prefix_audit.json`에 있다.
- 저장소 Python 코드에서 미래 shift·뒤 채움·중심 이동창·양방향 GRU·초기 여러 행의 통계 소급 적용 패턴을 검색하고 관련 추론 경로를 점검했다. 사후 라벨 분석은 추론 입력에 연결하지 않는다.

실행 중이던 학습은 중단하고, 수정한 생산용 규칙을 사용하는 `past_only_v3`로 검증을 다시 시작했다. 현재 프레임만 입력으로 받는 B checkpoint만 재사용하고 보정기와 수정 기준은 다시 학습한다. 원래 중첩 검증의 모델 용량·후보·채택 기준은 완화하지 않았다.
