# 중첩 검증을 적용한 4→5 보정 모델 결과

공식 Train의 실험 단위 5-fold를 바깥 평가로 사용하고, 각 바깥 학습 집합 안에서 B를 새로 3-fold×3-seed 학습했다. 새 B 모델 45개와 보정기를 실제 학습했다. 바깥 평가 실험은 안쪽 B의 학습·checkpoint 선택·전처리·보정기·임계값 선택에서 모두 제외했다.

원본 final_rules3.py에서 미래 참조를 제거하고 관측된 prefix만 사용하는 생산용 규칙을 모든 경로에서 공유한다. 현재 프레임만 사용하는 B checkpoint 30개는 중단한 이전 실행에서 재사용했고, 남은 15개를 추가 학습했다. 보정기와 기준은 모두 다시 학습했다. 실제 실험 prefix 불변성 감사도 수행했다.
주 후보는 실행 전에 정한 시간 없는 과거 상태 모델(history)이다. 나머지 모델은 대조군이며 결과를 보고 주 후보로 교체하지 않았다. 보정은 4→5만 가능하다. 실험별 총 가중치 1과 L2 규제를 적용했고, 안쪽 검증 기준을 통과하지 못하면 해당 fold는 보정하지 않는다.

## 해석 및 한계

규제를 둔 작은 선형 gate가 보정할 수 있다는 가설을 검증한 결과다. 보정 기준이 꺼진 경우는 안전하게 고칠 근거를 확보하지 못했다는 뜻이며, 모든 형태의 이력 모델이 불가능하다는 증거는 아니다. Inner B는 outer B보다 적은 실험으로 학습되어 확률 분포 차이가 있을 수 있다. 이전 탐색의 선택 편향과 새로운 재학습 변동은 이번 고정 OOF bootstrap으로 제거되지 않는다. 과적합 부재를 증명했다고 주장하지 않는다.

OOF와 Validation의 절대 F1을 공개 제출 점수 0.93과 대응시키지 않는다. 이 중첩 학습은 Test를 읽거나 제출 파일을 만들지 않았다. 별도 제출 감사에서는 기존 Test 관측으로 제출 파일을 재현했으며 정답·학습·모델 선택에는 사용하지 않았다.

## 산출물·검증

`past_only_v3/protocol.json`: 실행 전 조건과 소스 hash. `past_only_v3/outer_*/inner_*`: 실험 분할, 전처리, checkpoint 45개와 학습 곡선, holdout 확률. `past_only_v3/nested_oof/`: 평가 예측, 전체·실험별·조건별 지표와 수정 내역. `past_only_v3/*_candidate.joblib`: 연구 후보. `past_only_v3/deployment_gate.joblib`: 채택 판단을 반영한 모델. `past_only_v3/decision.json`: 사전 기준별 통과 여부.

미래 불변성·실험 분리·시간 없는 특징의 시간 배율 불변성·4→5 외 변경 금지·근거 부족 시 보정 중단·중복 시각 검사·초기 전압 규칙을 포함한 전체 prefix 불변성을 포함한 단위검증 7개를 통과했다. 독립 감사는 45개 모델의 fit/selection/holdout 분리, 전처리와 checkpoint 선택, OOF 배열, 보정 결정, 전체 F1을 재구성했다. 결과는 `past_only_v3/audit_checks.json`에 있다.
