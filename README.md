## 설치와 추론

저장소 루트에서 실행한다. 학습 데이터나 미리 계산한 확률·특징 파일은 추론에 필요하지 않다. `weights/`에 저장한 가중치와 전처리를 그대로 불러오며, 학습하거나 전처리를 다시 적합하지 않는다.

```bash
python -m pip install -r requirements.txt
python test.py --input <CSV> --image_root <이미지 폴더> --output <저장 경로>
```

공식 데이터 경로를 사용하는 예:

```bash
python test.py --input data/battery_data_light/test/test.csv --image_root data/battery_data_light/test --output reproduced.csv
python check_submission.py --data_dir data/battery_data_light --final submission_stage6.csv
```

입력 CSV에는 `sample_id`, `experiment_id`, `relative_time_s`, `image_path`와 원본 센서 열이 필요하다. `image_path`는 `--image_root` 기준 상대 경로다. 출력은 입력과 같은 행 순서의 `sample_id,label` 두 열이며, 라벨은 1~6의 정수다. 정답 `label` 열이 입력에 있으면 추론 전에 제거한다.

각 행은 **입력 CSV에 실제로 주어진 같은 실험의 현재·과거 관측만** 사용한다. 실험을 분리하거나, 입력 순서를 섞거나, 미래 행을 제거해도 남은 관측까지의 결과는 같다. 과거 관측을 제거한 임의의 중간 구간은 원래의 전체 이력과 정보가 다르다.

가중치 전체는 약 3.2 MB이며 파일마다 1 MB 미만이다. 별도 다운로드나 Drive 링크 없이 저장소에 전부 포함한다. `check_submission.py`는 제공된 가이드에 따라 작성한 자체 점검 구현이며, 별도 Drive에서 배포된 운영진 스크립트 원본은 아니다. 결과는 `verification/self_check.json`에 기록한다.

## 모델과 특징

추론 순서는 **B 3-seed 확률 평균 → T1 45°C 규칙 → 학습 경계 보정 → S3 규칙**이다.

### B 융합 모델

- seed 42·43·44를 평균한다. 외부 사전학습 모델은 사용하지 않았다.
- 현재 열화상 RGB 이미지를 종횡비를 유지해 128×128 캔버스로 만들고 패딩 마스크를 함께 사용한다.
- 3×3 합성곱 4층(stride 2, GroupNorm, ReLU; 16→32→64→64채널)으로 8×8 공간 토큰을 만들고 2D 위치 정보를 더한다.
- 현재 전기·온도 센서 6종을 쿼리로, 가스·압력 11종과 이미지 토큰을 센서 조건부 attention으로 요약한다. 센서, 가스 평균, 이미지 평균, 가스 attention, 이미지 attention을 MLP에 넣어 6클래스 확률을 낸다.
- 센서 결측은 학습 실험 중앙값으로 채우고, 학습 평균·표준편차로 정규화한다. 결측 표시도 입력한다. 배터리 종류·용량·SOC·가열방식·실험 ID·정답은 분류 입력으로 사용하지 않는다. 실험 ID는 이력을 실험별로 분리할 때만 쓴다.

### T1 규칙과 학습 경계 보정

현재까지 `meas_t1`의 누적 최대가 45°C 미만이면 1단계, 이상이면 최소 2단계로 정한다. 이를 기준 예측으로 사용한다.

| 학습 보정 | 대상 | 고정된 최종 기준값 |
| --- | --- | --- |
| 5→6 | 기준 예측 5 | 0.7 |
| 6→5 | 기준 예측 6 | 0.7 |
| 4→3 | 기준 예측 4 | 0.5 |

세 학습 보정은 원래 기준 예측에 대해 각각 판단한다. 5→6으로 바뀐 행에 학습 6→5 보정을 다시 적용하거나, 6→5로 바뀐 행에 학습 5→6 보정을 재실행하지 않는다. 4→5는 꺼져 있고 3→4는 저장된 기준값 1.01로 꺼져 있다.

보정기는 얕은 HistGradientBoosting(120회, 잎 5, 깊이 3, 학습률 0.05, 잎당 최소 64행, L2 5)을 사용한다. 입력은 현재 센서값, 과거 누적 극값·극값 이후 경과 시간, 최근 30·60초 센서·B 확률 이력, seed 간 확률 차이 등이다. 4→3에는 전압 상대 하락·T1/T2 누적 최대·과거 2/3/4 확률 이력도 넣는다. 이미지 특징맵을 보정기에 직접 넣지는 않는다.

### 마지막 S3 규칙

위 보정 결과에 다음 규칙을 **한 번** 적용한다. `meas_t1_plus_t2`는 CSV의 관측 열을 그대로 사용한다.

- 현재까지 T1+T2 최고값이 300°C 이상이고, 현재 합계가 그 최고값과 같으며 예측이 6이면 **5로 내린다**.
- 현재까지 T1+T2 최고값이 300°C 이상이고, 현재 합계가 그 최고값보다 5°C 이상 낮으며, 현재까지 초기 전압 기준의 80% 미만 하강을 관측했고, 예측이 4 또는 5이면 **6으로 올린다**.
- 초기 전압 기준은 첫 5개 관측 행이 도착하는 동안에만 갱신한다. 각 행 시점의 기준을 사용하며 앞 행에 소급 적용하지 않는다. 하강 관측 여부도 그 시점부터만 유지한다.

S3는 앞선 학습 보정의 5/6 결정을 바꿀 수 있다. 두 방향의 조건은 S3 입력 예측에서 동시에 정하고 반복하지 않는다. 기존 4→3 보정은 유지된다. 실험 전체 최고값·길이·종료 시각, 뒤 채움, 미래 전환시각·정답은 사용하지 않는다.

## 학습·검증 구성

제출 B 가중치는 공식 Train 78실험을 실험 단위 62/16으로 나누어 학습·체크포인트 선택에 사용했다. 전처리는 62개 학습 실험에서만 적합했다. B 모델 학습 설정은 클래스 빈도^−0.5 가중 CE, AdamW(lr 3e-4, weight decay 1e-4), batch 64, 15 epoch이며 선택 실험의 Macro F1이 가장 높은 epoch를 저장했다.

보정기는 Train 78실험의 실험 단위 5-fold B OOF 확률로 학습했다. 각 OOF 기본 모델의 전처리도 해당 모델의 학습 실험에서만 적합했다. 보정 기준값은 학습 실험 내부 GroupKFold 3-fold에서 선택했다. 실험×정답별 가중치를 균형화하고, 개선 F1·고친 행 대 악화 행·개선 실험 수·실험 하나 제외 시 이득을 검사했다. 개발 과정의 분할·배터리 조합 제외 검토로 보정 구성을 정했다. Test 정답은 학습·선택에 사용하지 않았다.

S3는 H=300, d=5의 고정 규칙이며 추가 가중치 학습이 없다. 제출 가중치의 공식 Validation 19실험 전체(E16 포함) Macro F1은 **0.77453**이었다. 별도로 고정 구조를 재학습한 전체 97실험의 실험 단위 5-fold OOF는 **0.85252**였다. 후자는 제출 체크포인트 자체의 점수와 구분한다. Train·Validation은 개발 중 이미 살펴본 자료이므로 새로운 맹검 평가나 비공개 테스트 점수 추정치가 아니다.

학습 코드는 다음과 같이 읽거나 실행할 수 있다. 운영진 추론에는 이 단계가 필요하지 않다. 실행하면 `weights/`를 새로 학습한 결과로 갱신한다. 학습 진입점은 공식 Train만 읽으며, Validation과 Test를 읽지 않는다. 하드웨어·라이브러리 차이로 재학습 결과가 달라질 수 있으므로 최종 제출 재현은 포함된 가중치를 사용한다.

```bash
python train.py --data_root data/battery_data_light --work runs --device cuda
```

```bash
python audit_causality.py --data_dir data/battery_data_light
```
