# 배터리 열폭주 6단계 분류 — 최종 제출 코드

최종 파일: `submission_rule1_56_65_lower_past.csv` (공개 리더보드 Macro F1 [0.96__])
`test.py` 출력이 이 파일과 바이트 단위로 같다(`self_check.py` 1번 항목).

## 실행

```bash
pip install -r requirements.txt
python test.py --input <CSV> --image_root <이미지 폴더> --output <저장 경로>
# 예: python test.py --input data/battery_data_light/test/test.csv --image_root data/battery_data_light/test --output submission.csv
python self_check.py --data_dir data/battery_data_light --final submission.csv   # 운영진 점검 5가지 자체 확인
```

- `test.py`는 학습·전처리 재적합 없이 `weights/`만 읽는다. CPU에서 실행되며 test 전체 약 10초.
- 입력 CSV의 행만 본다. 각 행은 같은 실험에서 그 행 시각까지의 행만 쓴다. 그래서 행 순서를 섞거나, 실험을 나눠 넣거나, 뒤쪽 행을 빼도 결과가 같다.
- 환경: Ubuntu 22.04, Python 3.10.12. 학습은 NVIDIA RTX 5080, 추론은 CPU.

## 파일

| 파일 | 내용 |
|---|---|
| `model.py` | B 모델 로더(`BModel`), t1 45°C 규칙(`rule1`), 하위 경계 피처(`lower_features`), 전체 예측(`predict_labels`) |
| `train.py` | 학습 전체 절차(B → B OOF → 5→6·6→5·4→3 보정) |
| `test.py` | 가중치로 예측만 |
| `self_check.py` | 최종 파일 재현, 재실행, 행 섞기, 실험 나눠 넣기, 앞 60%만 넣기 점검 |
| `lib/` | B 모델 구조·학습(`abc_reference`), 시계열 피처·보정 HGB(`targeted_rule1`, `compare_abc_phase_history`), 6→5 보정(`precision.py`) |
| `weights/` | `B_seed42/43/44.pt`, `preprocessing.json`(train으로 적합한 센서 정규화 통계·클래스 가중치), `pipeline.joblib`(5→6·6→5 헤드), `lower_heads.joblib`(4→3 헤드) |

## 모델

```
행 입력 → [B 융합 모델] → [t1 45°C 규칙] → [4→3 · 5→6 · 6→5 경계 보정] → 단계 1~6
```

### 1. B 융합 모델 (직접 설계·학습, 사전학습 모델 없음)
- 입력(현재 행만):
  - 열화상 이미지: 비율을 유지해 128×128 캔버스에 넣고, 유효 영역 마스크를 함께 넣는다.
  - 전기·온도 센서 6종: `meas_v`, `meas_t1`, `meas_t2`, `atmp_t`, `thermal_t`, `indu_t`
  - 가스·압력 11종: `meas_p`와 가스 10종
  - 센서값은 train 중앙값으로 결측을 채우고 표준화한다. 결측 여부도 함께 넣는다.
  - 배터리 조건(`bat_class`, `bat_cc`, `soc_status`, `tr_method`)은 쓰지 않는다.
- 이미지 인코더: 3×3 합성곱 4층(stride 2, GroupNorm, ReLU, 16→32→64→64채널)을 거쳐 8×8 픽셀 토큰을 만들고 2D 위치 임베딩을 더한다.
- 가스 토큰: (값, 결측 여부)에 가스 종류 임베딩을 붙여 MLP로 토큰 11개를 만든다.
- **센서 조건부 attention**: 전기·온도 센서를 MLP로 쿼리로 만들고, 쿼리와 토큰의 내적으로 열화상 픽셀과 가스 토큰을 가중 요약한다.
- 출력: [센서, 가스 평균, 이미지 평균, 가스 attention, 이미지 attention]을 이어 붙여 MLP에 넣고 6클래스를 낸다.
- 학습 설정
  - 클래스 빈도^−0.5 가중 CE, AdamW(lr 3e-4, wd 1e-4), batch 64, 15 epoch
  - train 실험 20%(실험 단위)로 최고 Macro F1 epoch를 선택한다.
  - seed 42/43/44의 확률 평균을 쓴다.
- 같은 구조에서 읽기 방식 A(평균만)와 C(고정 쿼리)를 비교한 결과 B가 가장 좋았다.

### 2. t1 45°C 규칙
현재까지 `meas_t1` 누적 최대가 45°C 이상이면 2단계 이상, 미만이면 1단계로 정한다(양방향).

### 3. 경계 보정 3개 (HistGradientBoosting)
- 기준 예측(B + 규칙)이 해당 단계인 행만 판단한다. 세 보정은 서로의 결과를 다시 고치지 않는다.

  | 보정 | 대상 | 기준값 |
  |---|---|---|
  | 5→6 | 기준 5 | 0.7 |
  | 6→5 | 기준 6 | 0.7 |
  | 4→3 | 기준 4 | 0.5 |

- 트리 설정: 잎 5, 깊이 3, 120회, 학습률 0.05, 잎당 최소 64행, L2 5. 가중치는 실험×정답 단계별로 균형을 맞춘다.
- 학습 데이터: train 78실험. 입력 B 확률은 실험 단위 5-fold OOF다(B가 그 실험을 보지 않은 확률).
- 기준값: 학습 실험 3-fold로 고른다. 다음을 모두 만족할 때만 켜고, 아니면 끈다.
  - 이득 > 0
  - 고친 행 ≥ 2×망친 행 (6→5는 3×)
  - 개선 실험 수 > 악화 실험 수
  - 실험 하나를 빼도 이득

### 시계열 피처 (모두 같은 실험의 현재·과거 관측만)
- 센서 5종: 현재값(log), 누적 극값과의 차이, 극값 이후 경과 시간, 최근 60초 범위·기울기·변화량, 경과 시간
- B 확률 이력: 4·5·6단계 확률 과거 최고치, 최근 30·60초 평균·최대·변화, 마지막 6단계 예측 이후 경과 시간, seed 간 의견 차이
- 4→3 보정 추가 피처
  - 최고 전압 대비 현재 전압 비율·최저 비율·하락 폭
  - t1·t2 누적 최대, 45°C 도달 후 경과 시간
  - 전압이 최고 대비 95%·90% 아래로 내려간 뒤 경과 시간
  - B의 2·3·4단계 확률과 최근 60초 평균, 3·4단계에 처음 도달한 뒤 경과 시간
- 관측 개수에 의존하는 특징(관측 간격, 관측 개수)은 4→3 보정에서 쓰지 않는다. test에 10·15초 간격 실험이 있기 때문이다.
- 실험 전체 최댓값·길이·종료 시각, 뒤 채움, 미래 행은 쓰지 않는다.

## 학습·검증 구성
- 모든 분할은 실험(`experiment_id`) 단위다.
- 보정 채택은 내부 검증으로 정했다. train+validation 97실험 중 개발 77실험으로 B를 재학습하고 교차검증해서 고른 뒤, 떼어 둔 20실험과 배터리 조합 통째 제외 평가로 확인했다.
  - 4→5 보정은 처음 보는 배터리에서 손해라 끈다.
  - 4→3 보정은 결과를 보기 전에 정한 규칙(4개 관측 간격 모두 이득 + 배터리 조합 제외 평균 이득)을 통과해 쓴다.
- `train.py`의 보정 학습 단계를 다시 돌리면 `weights/`의 헤드와 test 예측이 0행 차이로 같다.
