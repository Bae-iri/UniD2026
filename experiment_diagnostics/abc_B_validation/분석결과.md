# ABC B의 Validation 실험별 성능

분석: `/home/ubuntu/leewon/abc_runs/current_query_v1/ensemble_B_validation_predictions.csv`의 3-seed 확률 평균 B. 원본 파일은 서버 내부 코드에서만 처리했고 행별 정보는 출력/복사하지 않았다. 또 다른 `/home/ubuntu/leewon/UniD2026/abc_runs/current_query_v1` 사본과 입력 파일 SHA256이 동일했다. 집계 점수는 저장된 ensemble_scores.csv와 일치했다.

## 결과

- Validation 10,200행, 19실험. 전체 Macro F1=0.696346, Accuracy=0.840882.
- 실험별 실제 존재 클래스 기준 Macro F1 범위0.299421~0.960709. 실험에 없는 클래스를 일괄0으로 넣어 생기는 차이는 피했으나 클래스 구성·표본 수 차이는 여전히 존재한다.
- 익명 E16: 1,543행 중842오류, 전체1,623오류의51.88%. 실험별 present-class Macro F1=0.402277, Accuracy=0.454310.
- E16의5→4 오분류542건. 전체 Validation의5→4 오류557건 중97.31%가 이 실험에 집중됐다.
- E16: 실제5단계590건인데5단계 예측은9건. 5단계 F1=0.0200. 실제4단계는0건인데4단계 예측은560건.
- E16의 세 seed present-class Macro F1은0.3301/0.4512/0.3642. seed 하나만의 실패가 아니다.
- E16의3→2 오분류도222건.
- E14는 실험별 F1이 가장 낮지만97행·33오류로, 전체 점수 영향은 E16보다 작다.

## 민감도

E16을 제외해서 계산하면 전체 Macro F1은0.696346→0.814221. 이는 어려운 실험의 영향 확인용이며 삭제하거나 평가 대상을 바꿀 근거가 아니다. 큰 실험은 F1에 단순 행 가중 평균 형태로만 영향을 주지 않으며 클래스별 정밀도·재현율을 함께 바꾼다.

실험 단위2,000회 bootstrap의 고정 모델 Macro F1 95% 구간은0.5561~0.8542. 19개 실험의 구성에 따라 점수가 크게 움직일 수 있다는 신호이며 Test 점수 구간·재학습 불확실성이 아니다.

## 해석과 다음 단계

실험 간 성능 차이는 크고, 특히 한 실험의5단계가4단계로 대거 분류되는 실패가 전체 점수에 크게 작용한다. 다만 Test가 실제로 더 쉬운 실험으로 구성됐는지, 센서/이미지/조건 차이가 원인인지, 정답 기준 차이가 있는지는 이 집계로 알 수 없다. label 오류라고 단정하지 않는다.

다음은 어려운 실험을 삭제하지 않고 A/B/C의 같은 실험·클래스 혼동행렬을 비교하는 것이다. 모두 같은5→4 실패라면 공통 입력/학습/실험 일반화 문제를 우선 조사하고, B에 집중되면 현재 query 기반 선택의 영향을 살핀다. 구조를 바꾸기 전에 이 차이를 확인한다.

모든 실제 experiment_id는 정렬 순서 E01~E19로 익명화했다. 전체 표는 experiment_summary.csv, 클래스별 F1·실제/예측 개수·혼동행렬·seed별 점수는 report.json에 있다. 원본/행별 예측은 포함하지 않는다.

