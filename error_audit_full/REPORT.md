# rules3 전체 오류 재분석

분석 기준: 원본 3-seed B + rules3. 내부 임계값은 fit 62개 실험에서 계산한 기존 기준을 고정했다. dev 16개 실험 및 validation 19개 실험을 분석했다. 저장된 기존 예측과 모든 행의 일치를 확인했다. Test 정답은 없으며 public 0.93의 오류 수를 계산한 것이 아니다. Test 파일을 읽지 않았다.

## 1. 단계별 실제 표본 / 놓친 정답 / 잘못 유입된 예측

## 2. 평가요소와 점수 병목

로컬 평가 코드는 6단계 Macro F1 = (F1₁+…+F1₆)/6, F1 = 2TP/(2TP+FP+FN)을 사용한다. 공식 대회 페이지를 이번에 확인한 것은 아니며 저장된 코드의 평가 정의다. 행 정확도와 다르다. 표본이 많은 1단계가 완벽해도 6단계의 낮은 F1을 보상하지 못한다.

| split | scope | rows | experiments | errors | accuracy | macro_f1 |
| --- | --- | --- | --- | --- | --- | --- |
| dev | all | 6788 | 16 | 618 | 0.908957 | 0.81015 |
| validation | all | 10200 | 19 | 1273 | 0.875196 | 0.728644 |
| validation | noE16 | 8657 | 18 | 446 | 0.948481 | 0.86853 |


validation noE16에서 6단계 precision은 60.20%, recall은 76.96%다. 실제 6단계를 놓치는 것뿐 아니라 5를 6으로 너무 일찍 올리는 예측이 precision을 크게 깎는다. dev도 5·6단계 F1이 각각 65.66%, 69.21%로 낮다. 2↔3 오류 수만 보고 우선순위를 정하면 이 병목을 놓친다.

validation 전체에서는 4단계 precision이 34.44%, 5단계 recall이 37.39%다. 주원인은 E16의 실제 5를 4로 보내는 542건이다. 이 오류는 4단계 FP와 5단계 FN을 동시에 늘린다. E16은 전체 1,273오류 중 827건(64.96%)을 차지한다. 제외하면 Macro F1이 0.728644→0.868530으로 바뀐다. 제외 성능은 보조 지표이며 전체 성능의 대체값이 아니다.

## 4. 오류 이유: 확인된 사실과 해석

### A. 5↔6: 전환 타이밍과 후보 선택의 혼동

validation noE16의 5→6은 111건/13개 실험, 6→5는 53건/8개 실험이다. 164건 중 154건(93.90%)은 정답이 원본 확률의 상위 두 후보에 있다. 116건(70.73%)은 세 seed 중 하나 이상이 정답을 냈다. 125건(76.22%)은 실제 전환에서 60초 이내이고 120초 초과는 3건뿐이다. dev도 95건 중 94건이 top2, 81건(85.26%)이 seed 중 하나 이상 정답이고 78건(82.11%)이 전환 60초 이내다.

해석: 표현 전체가 완전히 실패한 경우보다는 인접 단계 간 확률 배분·전환 타이밍·seed 결합 문제가 유력하다. 전환 근처의 정답 행에도 같은 확률 패턴이 있을 수 있으므로 이것만으로 교정 규칙을 확정할 수는 없다. 조기 6과 지연 6을 함께 평가하는 전환 모델/확률 보정이 다음 실험 대상이다. 열화상 하한 하나로 해결된다는 근거는 없다.

### B. 2↔3: 조기 진입과 늦은 진입/회귀가 섞임

dev 2→3은 149건, 3→2는 275건이다. validation noE16은 각각 49건, 168건이다. 3→2 중 이전에 올바른 3 예측이 있었던 행은 dev 37건, validation noE16 29건뿐이다. 상태 유지 규칙은 이 일부를 겨냥하므로 나머지 최초 진입 실패를 해결할 수 없다.

2→3 오류의 원본 confidence 중앙값은 dev 85.69%, validation noE16 96.92%다. dev 92/149, validation 31/49건은 세 seed 모두 정답을 내지 못했다. 단순 저신뢰도 제거로 조기 3을 모두 잡을 수 없다. dev 3→2는 114/275건이 전환에서 120초보다 멀고 176건은 세 seed 모두 틀렸다. 전환을 몇 초 미루는 규칙만으로 긴 오분류 구간까지 해결하기 어렵다.

### C. E16의 5→4: 긴 구간의 공통 실패

validation 5→4 총 557건 중 542건(97.31%)이 E16이다. 총 557건 중 504건은 실제 전환에서 120초보다 멀고 545건은 세 seed 모두 정답을 내지 못했다. 445건은 원본 최대 확률이 0.9 이상이며 정답이 top2에 있는 경우는 142건뿐이다. 5↔6과 달리 확률 경계만 조금 움직이는 해법의 범위가 작다.

기존 개입 실험에서는 E16의 현재 센서·이미지 표현이 학습 4단계 중심에 더 가까웠고 과거 극값/시간 특징 추가가 5단계 복원에 도움이 됐다. 따라서 현재 관측만으로 진행 상태를 구분하지 못한다는 가설이 있다. 다만 과거 극값과 단순 경과시간의 효과가 섞여 있고 다른 단계 손실도 있어 물리적 원인 확정은 아니다. 근거: experiment_diagnostics/five_to_four_findings/분석결과.md. 그 실험의 절대 F1은 rules3와 다른 모델 기준이라 직접 비교하지 않는다.

### D. 규칙 자체가 주원인인가?

아니다. rules3가 원본 정답을 오답으로 바꾼 행은 dev 8건, validation 전체 3건이다. 반대로 원본 오답을 정답으로 만든 행은 각각 154건, 353건이다. 잔여 오류 중 원본과 같은 오답은 dev 608/618건, validation 1270/1273건이다. 기존 규칙을 미세 조정하는 것만으로 모델의 주된 공통 오류가 사라지지 않는다. 각 규칙의 순차 기여와 훼손은 rule_steps.csv에 저장했다.

## 5. 왜 직전 보정 이득이 작았나

직전의 확인 유지+t1 상한은 2→3 조기 오판, 4↔5, 5↔6을 수정하지 않으며 3→2 일부만 바꾼다. E16을 제외한 validation에서는 실제로 바꿀 수 있던 정답 복원이 7건에 그쳤다. 이 결과는 해당 보정의 범위가 좁았다는 뜻이다. 전체 시스템의 개선 여지가 작다는 증거는 아니다. 반대로 큰 개선이 반드시 존재한다고도 현재 자료만으로 보장할 수 없다.

추가로 기존 전체 시스템 5-fold OOF(78개 실험, 33,522행)를 확인하면 rules3 Macro F1 0.844551, 열화상 하한 추가 0.837572(-0.698%p, 수정 62/훼손 106), t1 상한 추가 0.846222(+0.167%p, 수정 171/훼손 88), 두 규칙 추가 0.839242다. 열화상 하한의 손실은 6단계 F1 0.740455→0.700926에서 드러난다. 기존 자료의 미미한 이득을 무시하고 규칙을 늘리는 접근은 이 재검증과도 맞지 않는다. 근거: four_rule_cv/runs/group5_seed42_43_44_v1/train_oof/summary.csv. 새 fold 모델의 절대 성능은 저장된 원본 B와 직접 비교하지 않는다.

## 6. 다음 개발과 판단 기준

1. 일반 실험에서는 5↔6 전환 모델/확률 결합을 우선 비교한다. 같은 B 확률을 입력으로 쓰고 조기 6 감소와 실제 6 지연을 함께 평가한다. 기준은 오류 수뿐 아니라 5·6 precision/recall/F1, 전체 Macro F1, 수정/훼손, 실험별 분포다.

2. 2↔3은 조기 3 / 최초 3 진입 지연 / 3 예측 후 2 회귀를 나누어 분석한다. 단일 debounce로 묶지 않는다. 긴 구간의 공통 오류에는 센서 이력과 조건별 특징의 추가 정보가 있는지 검증해야 한다.

3. E16 유형은 별도 이력 가설로 다룬다. 특정 실험 ID를 알아야 작동하는 규칙 대신 과거 극값·현재와의 차이·시간 특성으로 일반화되는지를 학습 실험 밖에서 검증한다. 전체/제외 성능 모두 보고한다.

4. 평가 단위는 실험이다. 같은 실험의 인접 행을 train/holdout에 섞지 않는다. 임계값·보정기 학습은 fit에서만 하고, 실험별 paired 차이와 한 실험 제외 민감도를 함께 확인한다. 샘플 수가 적거나 단계가 없는 실험의 고정 6클래스 Macro F1은 비교에 주의한다. 조건별 행 오류율은 표본 구성·실험 길이에 영향받으므로 배터리 조건의 인과 효과로 해석하지 않는다.
