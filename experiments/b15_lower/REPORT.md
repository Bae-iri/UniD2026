**검증 방법과 범위**

- 기존 `final_s3.py`의 기본 모델 OOF는 전역 분할에서 만들어졌다. 다른 fold의 학습용 확률을 만든 기본 모델이 평가 fold를 봤을 수 있다. S3 선택에 쓰인 다른 fold의 보정 모델도 평가 fold 라벨을 봤을 수 있으므로, 기존 결과를 완전 중첩 검증으로 취급하지 않았다.
- 이번에는 기존에 별도로 학습되어 있던 **180개 기본 모델**의 확률을 감사 후 재사용했다. 모든 바깥 평가 실험을 기본 모델의 학습·전처리·체크포인트 선택, 보정 모델 학습에서 제외했다. 보정 학습용 확률도 해당 바깥 학습 실험 안에서 다시 분리된 모델이 생성한 것이다. 학습 manifest, 확률·가중치·전처리 해시, 최고 epoch를 검사하고, 각 모델의 정규화 값을 학습 행에서 독립적으로 다시 계산했다.
- 제출 구조와 임계값을 고정했다: 4→5 끔, 5→6 0.7, 6→5 0.7, 3→4 끔, 4→3 0.5, S3 `H=300`, `d=5`. 가설과 임계값 자체는 과거에 살펴본 데이터에서 유래했다. 이번 검증은 새로운 비공개 자료에 대한 맹검이 아니다.
- 다른 분할 검증은 과거의 77실험 개발 자료를 사용했다. 이전에 이미 확인했던 최종 확인용 20실험은 이번 선택·학습·평가에서 다시 열지 않았다. 두 검증 묶음은 서로 일부 겹친다.
- 학습 자료는 모두 5초 간격이지만 제출 테스트는 5초 2,442회, 10초 605회, 15초 393회의 간격이 섞여 있다. 각 바깥 평가 실험을 10초의 두 시작 위치, 15초의 세 시작 위치, 10/15초 교대, 관측 30% 무작위 삭제로 변형했다. **과거 특징은 남은 관측에서 다시 계산**했다. 2개 묶음 × 8개 관측 조건 모두에서 S3 개선량의 bootstrap 하한이 양수였다. 반복 검증에서 S3 점수는 **0.86741–0.87585**였다.
- `H ∈ {300,400}`, `d ∈ {3,5,10}`의 6개 주변 설정을 진단한 결과, 두 묶음 모두 개선됐다. 개선량은 각각 **+0.01781–0.01970**, **+0.01619–0.01749**다. 새 설정을 선택하지 않았다.
- 용량·SOC·가열 방식별 점수도 기록했다. 이는 조건별 집계이며, 용량 전체를 학습에서 제외한 실험은 아니다. 4.8 용량에서는 S3가 한 검증 묶음에서 -0.0004 악화됐고, 일부 용량·가열 방식의 절대 성능도 낮았다. 모든 조건의 개선을 주장하지 않는다.
