# Nested CV (파이프라인 전체를 바깥 교차검증 안에서 반복)

- train+validation 97실험을 실험 단위 바깥 5-fold로 나눴다(`StratifiedGroupKFold`, 배터리 조합 층화, seed 20261115).
- 각 바깥 fold에서 나머지 실험만으로 아래를 처음부터 다시 했다. 바깥 fold는 평가에만 썼다. Test는 읽지 않았다.
  - B 재학습(안쪽 5-fold × 3 seed OOF + 최종) — `b_nested.py`
  - 5→6·6→5·하위 보정 학습과 기준값 자동 선택
  - 하위 보정 채택 규칙(안쪽 OOF 4개 간격 + 안쪽 배터리 조합 제외) — `evaluate.py`

## 결과 (97실험 바깥 fold 예측, Macro F1)

| 방법 | 5s | 10/15s | E_e5bc 제외 5s | 기준 대비 5s | bootstrap 하한 | 나아진/나빠진 실험 |
|---|---:|---:|---:|---:|---:|---:|
| 기준 (B + t1 45°C) | .8227 | .8244 | .8558 | — | — | — |
| S40 (4→5 + 5→6 + 6→5) | .8552 | .8552 | .8867 | +3.25 | +2.30 | 67 / 13 |
| 5→6 + 6→5 | .8528 | .8531 | .8855 | +3.02 | +2.18 | 65 / 14 |
| **최종 (5→6 + 6→5 + 4→3, 제출 구성)** | **.8537** | **.8539** | **.8866** | **+3.10** | **+2.26** | 67 / 15 |
| fold 안 채택 규칙이 고른 구성 | .8549 | .8551 | .8878 | +3.22 | +2.37 | 69 / 15 |

- 4→3은 바깥 fold 5개 모두에서 채택 규칙을 다시 통과했다. 기준값은 4개 fold에서 0.5, 1개 fold에서 0.7이었다. 3→2와 3→4는 fold에 따라 달랐다.
- 4→3 자체의 이득은 +0.09점(고친 30행, 망친 4행)으로 작다. 홀드아웃 개발 수치(+1.8)는 재학습 B의 3→4 오답이 많아 부풀려진 값이었다.
- 4→5를 뺀 비용은 같은 분포 안에서 약 0.15점이다(S40 .8552 vs 최종 .8537).
- 바깥 fold별 최종(5s): .7954 / .8915 / .8994 / .8897 / .8334.
