# 5→4 오분류: 다중 진단 결과와 해결 후보

재학습 없는14개 개입×ABC B3seed, seed42 인코더를 고정한9개 선형 분류기, 현재/과거 특징5조건, 추가2개 Train 실험 분할, 시간/피크 분리3조건을 실행했다. 신경망 장시간 재학습·Test 접근·행별 결과 공개는 하지 않았다. CPU 선형분류기는 실제 fit에서 학습했다. 기존 모델·checkpoint는 변경하지 않았다.

## 결론

가스0 단독 원인설은 지지되지 않는다. E16의 현재 센서/이미지 표현이 학습4단계와 비슷하게 나타나고, 두 모달리티의 결합도5보다4를 강화하는 양상이다. 과거 상태와 시간 정보는5→4 문제를 완화하는 유망한 후보지만, 정확한 물리적 원인이나 최종 Test 성능 개선을 입증하지는 않는다.

가스 제거는 악화. 이미지 제거는E16의5단계 정답을6→105건으로 늘리지만 전체F1을0.3672로 크게 낮춘다. 특정 샘플의 이미지 경로가 잘못된 방향으로 작동하는 단서이지 이미지 전체를 버릴 근거가 아니다. 제거 개입은 학습 때와 다른 분포여서 재학습 효과와 같지 않다.

가스/이미지의5−4 logit factorial 상호작용 평균은E16 실제5단계에서-0.740, 다른 실험의 실제5단계에서는+0.331이었다. head의 비선형 결합에 대한 진단이며 물리적 인과 관계가 아니다.

E16의 이미지 attention 정규화 entropy는평균0.788, 다른5단계는0.439로 더 분산되어 있다. 영상 신뢰도나 품질 자체를 측정한 값은 아니므로 흐림/가림/정렬 문제라고 단정하지 않는다.

## 2. 현재 표현만 재결합한9개 선형 분류기

같은원래fit만으로 scaler/PCA/분류기를 학습하고 dev/Validation에서 평가했다. 단일센서/가스/이미지, 두모달리티 조합, 전체요약, 원래head입력, PCA 교차항을 비교했다.

어느 후보도 현재정보의 조합만으로E16의5단계를 충분히 복원하지 못했다. 교차항 추가도 개선되지 않았다. 전체 표는 ../five_to_four_probes/probe_summary.csv. 인코더가 이미 전체모달리티로 학습되어 있으므로 image-only 결과는 독립적으로 학습한 영상모델 성능이 아니다.

fit에서만 정규화한 특징 중심 거리 기준, E16 실제5단계 중센서98.98%, 이미지87.12%가fit5단계중심보다fit4단계중심에 가까웠다. 가스는27.97%였다. 평균중심 거리는 표현상의 유사도일뿐 정답오류나 물리적 동일상태를 입증하지 않는다.

## 실행 가능한 해결 방향

1. 기존공개점수0.91모델은보존한다.가스/이미지를일괄무시하거나5단계로강제하지않는다.
2. 근거가생긴후보는현재까지관측한최대온도·최소전압·현재와의차이·극값이후시간이다. 먼저ABC B의직접head경로에작은추가분기로넣고, query는유지하는통제비교가적절하다. 동일추가학습예산B대조군과시간만추가하는대조군이필요하다.
3. 학습라벨을활용한단계전이규칙을바로강제하지않는다. 현재상태가비슷한전/후구간이라는가설은과거특징결과가시사하지만단계단조성은확인되지않았다.
4. 준비된선형모델은five_to_four_history_saved의current.joblib/current_past_extrema.joblib에저장했다. 재현가능한빠른후보이며신경망ABC와같은구조비교는아니다. Test성능과불규칙이력간격견고성은미확인이다.
5. 더많은구조를무작정돌리기보다선택기준을고정하고5단계이득과3단계손실을동시에확인한다.
