# 시간·진행 이력 4/5 보정 모델

원본 B+rules3에서 현재 4 또는 5로 예측한 행에만 적용하는 별도 이진 모델 4개를 실제 학습했다. B 자체의 재학습은 아니다. 원본 fit 실험의 실제 4/5 행만 학습하며 실험별 총 가중치를 동일하게 했다. dev/validation은 학습과 임계값 선택에 사용하지 않았다. HistGradientBoosting 150회, 7 leaf, learning rate .05, L2 1로 모든 비교의 용량을 고정했다. ID나 라벨 전환 시각을 특징으로 사용하지 않았다.

| 입력 | fit GroupCV 4/5 F1 평균 | dev 전체 F1 | validation 전체 F1 | validation E16 제외 |
|---|---:|---:|---:|---:|
| 원본 B+rules3 | 해당 없음 | .810150 | .728644 | .868530 |
| 현재 센서 | .907691 | .796023 | .728670 | .857351 |
| 현재+시작 후 경과시간 | .911698 | .801415 | .728355 | .858092 |
| 현재+과거 극값·현재와의 차이(시간 제외) | .952118 | .820882 | .739615 | .861716 |
| 현재+극값+극값 이후 시간+경과시간 | .949148 | .815842 | .738756 | .859272 |

GroupCV는 fit 내부 실험 5-fold이며 보정 모델의 실제 4/5 binary 평가다. 전체 시스템 OOF가 아니고 오른쪽 전체 6클래스 F1과 직접 비교하지 않는다. dev/validation은 앞선 작업에서 반복 분석된 자료이며 독립적인 최종 검증이 아니다.

## 결과

이번 고정 모델에서는 단순 시간이 핵심이라는 가설을 지지하지 않는다. 시간 없는 극값 모델이 시간 포함 후보보다 dev/validation과 GroupCV에서 모두 높았다. 따라서 앞으로 시간 입력을 무조건 강화하기보다 과거 상태의 추가 정보에 초점을 맞추는 것이 타당하다. 이 결과는 모든 신경망 구조에서 시간 정보가 불필요하다는 증거는 아니다.

극값 후보는 dev 33건 복원/14건 훼손, validation 77건 복원/27건 훼손이었다. E16 실제 5단계 정답은 6→71건, 5→4는 542→477건이다. E16 제외 validation은 12건 복원/27건 훼손으로 하락한다. E16 개선 일부를 다른 실험 손실로 얻었으므로 최고 제출을 대체할 수준은 아니다. 시간 포함 후보는 E16 정답 73건으로 극값 대비 2건 증가했지만 전체 성능은 낮다.

## 파일 및 검증

run_v1/{current,elapsed,extrema,history_time}.joblib에 실제 학습 모델, 입력 열, 모드, fit 실험 목록을 저장했다. 모델 적용 시 train.py와 동일한 causal_features 및 모드별 열 선택이 필요하다. run_v1에는 scores.csv, fit_groupcv.csv, per_experiment.csv와 dev/validation 예측 및 config.json도 있다.

기존 causal_features를 재사용한다. 현재까지 전압 최솟값과 온도 최댓값, 현재와의 차이, 선택적으로 극값 이후 시간과 경과시간을 실험별로 계산한다. 미래/종료시각은 사용하지 않는다. 해당 함수와 head의 기존 단위검증 3개가 통과했다. manifest sample_id 일대일 결합, fit/dev 실험 분리, 저장된 기준 라벨 일치를 확인했다. Test 접근·제출 생성·원본 모델 변경은 하지 않았다.
