# 5→4·6→5 오류 전용 모델

두 오류를 직접 줄이는 별도 모델을 학습했다. 이번에는 바깥 평가에서 실제 복원이 발생했다. **6→5는 크게 줄었고, E16의 긴 5→4 구간은 대부분 남는다.** 아래는 내부 지표이며 공개 점수 0.93의 개선을 입증한 결과가 아니다.

## 실제 결과

| 평가 | B+rules3 Macro F1 | 두 모델 적용 | 정답 복원 / 훼손 |
|---|---:|---:|---:|
| Train 78실험 중첩 OOF | 0.844551 | **0.858904** | **142 / 18** |
| 기존 B validation 전체 | 0.728644 | **0.749812** | **69 / 14** |
| 기존 B validation E16 제외 | 0.868530 | **0.889373** | **52 / 14** |

OOF에서 29개 실험의 Macro F1이 개선되고 7개가 악화했다. paired 실험 bootstrap의 F1 차이 95% 구간은 `[+0.007904, +0.022628]`이다. 어떤 실험 하나를 빼도 pooled F1 차이는 최소 `+0.012539`였다. 한 실험에만 맞춘 개선이라는 설명은 이 결과와 맞지 않는다. 다만 이미 탐색한 자료와 같은 outer fold를 다시 사용했으므로 새로운 blind 평가나 과적합 부재를 주장하지 않는다.

| 실제→예측 오류 | 기존 | 두 모델 적용 |
|---|---:|---:|
| OOF 5→4 | 164 | **115** |
| OOF 6→5 | 116 | **35** |
| validation 전체 5→4 | 557 | **539** |
| validation 전체 6→5 | 56 | **23** |
| validation E16 제외 5→4 | 15 | **13** |
| validation E16 제외 6→5 | 53 | **3** |
| validation E16 5→4 | 542 | **526** |

6→5 전용 모델만 적용하면 OOF 6→5는 116→23, validation 전체는 56→5다. 합본에서는 4→5 모델이 기존의 실제6/예측4 일부를 예측5로 옮긴다(OOF 12건, validation 18건). 이 행은 정답 복원으로 세지 않는다. E16 제외의 53→3은 이 이동의 영향을 받지 않는다.

부작용도 있다. validation 실제5→예측6은 111→125건으로 14건 증가했다. OOF는 같은 오류가 391→408건이다. 전체 지표는 개선됐지만 모든 실험이나 모든 방향이 좋아진 것은 아니다.

## 바꾼 학습 방식

- **4/5 모델:** 원본 B가 확신한 오답을 그대로 학습하지 않도록 B 확률을 입력에서 제외했다. 현재 물리 센서, 현재까지 온도 최고·전압 최저, 현재와의 차이·극값 이후 시간, 과거 60초 변화, 관측 간격·경과시간을 사용했다. 실제 4/5 표본과 B가 4로 예측한 학습 표본으로 구분기를 학습하고, 기존 예측4만 5로 변경한다.
- **5/6 모델:** 위 물리 이력에 세 seed의 현재 확률·의견 차이와 과거 30/60초의 4/5/6 확률 흐름, 과거 6 예측 이력을 추가했다. 실제 5/6 표본과 B가 5로 예측한 학습 표본을 사용하고, 기존 예측5만 6으로 변경한다.
- 두 모델 모두 HistGradientBoosting 120회, 최대 5 leaf·깊이3, 최소 leaf64, L2=5로 고정했다. 실험×정답 클래스별 가중치를 균등화했다. 행을 임의 분할하지 않았다.
- 두 판단은 원래 B+rules3 예측에 대해 동시에 내린다. 같은 행을 4→5→6으로 연쇄 변경하지 않는다. 1/2/3/6 예측은 보존한다.

## 과적합 억제와 선택

기존 검증에서 만든 안쪽 B OOF를 재사용했다. 각 바깥 평가 실험은 그 안쪽 B의 학습·checkpoint 선택·전처리 및 새 구분기의 학습·수정 기준 선택에서 모두 제외했다. B를 다시 수십 개 학습하지 않았다.

수정 기준 `.5/.7/.9`는 바깥 학습 집합 안의 실험 단위 3-fold로만 정했다. 복원이 훼손의 두 배 이상, 최소 3개 실험 개선, 개선 실험 수 우세, 어떤 실험 하나를 빼도 pooled 개선이 남는 조건을 요구했다. 최종 모델은 학습에서 **4/5=.9, 5/6=.5**를 선택했다.

두 모델은 각각 OOF 차이·bootstrap 하한·실험별 분포·한 실험 제외 민감도 조건을 통과했다. Validation은 모든 학습과 기준 선택 후 읽었다. 원본 B와 새 fold B 모두 전체/E16 제외 지표가 악화하지 않는 조건도 통과했다. 합본 역시 같은 채택 조건을 통과했다. 실행 전 조건은 `run_v1/protocol.json`, 결과는 `run_v1/decision.json`에 있다.

기본 .5로 무조건 적용한 대조군도 숨기지 않았다. 4/5의 경우 OOF 복원102/훼손99, validation E16 제외 복원8/훼손24로 불안정했다. E16 복원을 늘리려고 validation을 보고 기준을 .5로 낮추지 않았다. 기본 기준 결과는 `fixed05_*`로 저장했으며 채택 대상이 아니다.

새 fold B의 validation E16 제외에서는 합본 F1이 .860297→.864381로 올랐지만 bootstrap 차이 구간은 0을 포함했다. 이 결과와 과거 반복 탐색을 감안하면 실제 제출 개선은 여전히 확인이 필요하다.

## 미래 관측 금지 검증

모든 이력은 같은 실험에서 현재 시점까지로 끝난다. 미래 행·뒤 채움·중심 창·종료시각·전체 길이를 사용하지 않는다. 원본 rules3도 이미 수정한 현재·과거 구현만 호출한다. 정규화는 고정된 관측별 변환이고, HGB의 분할 기준은 학습에서만 적합된다.

단위검증 4개가 통과했다. 독립 감사에서 바깥 평가 예측, 모델 용량·보정 기준, 모든 F1을 재구성했다. 실제 78개 실험의 312개 prefix에서 두 모델의 **입력과 예측** 모두 이전 시점에 대해 불변이었다. 결과는 `run_v1/audit_checks.json`에 있다.

## 제출 후보

모델 선택이 끝난 뒤 고정된 모델로만 Test를 추론했다. 기존 0.93 제출을 먼저 현재·과거 코드로 정확히 재현하고 그 기준을 유지했다. Test에서 44개 prefix를 확인했으며, Test로 학습하거나 기준을 조정하지 않았다.

- `final_submit/submission_targeted56_past.csv`
- `final_submit/submission_targeted45_56_past.csv`

두 파일은 **동일하다.** 이번 Test에서 4→5 기준을 통과한 행이 없고, 기존 예측5를 6으로 바꾼 행만 **24개**다. 이것을 Test 오류 24건을 고쳤다는 의미로 해석하지 않는다. Test 정답은 없다. 기존 `submission_rules3.csv`는 보존했다. 새 제출의 공개 점수는 미확인이다.

파일 hash와 변경 수는 `run_v1/submission_manifest.json`에 있다. 실제 모델은 `run_v1/deployment_heads.joblib`에 저장했다.

## 남은 핵심 문제

E16의 실제5/예측4는 **526건 남는다.** 이번 모델은 이 실험에서 5를 확신하는 시점이 실제 5 구간 후반에 몰렸다. 뒤늦게 발견한 증거를 앞 시점에 소급 적용하지 않았다. E16의 긴 5단계를 해결했다고 보고하지 않는다.

다음 5→4 개발은 현재 특징의 기준을 낮추는 방식보다, **5단계 최초 진입을 알아볼 과거 사건·상태 표현과 학습 실험의 지원 부족**을 다루는 것이 필요하다. 이번에 확보한 6→5 후보와 이 남은 문제는 분리해 관리해야 한다.
