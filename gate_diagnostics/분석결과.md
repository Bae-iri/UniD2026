# 게이트 사후 진단 결과

분석 대상: B_gate seed42 best epoch11, B_image_gate seed42 best epoch6. 재학습 없이 CPU, batch64, Validation/Test 전체 행을 평가했다. 원본/행별 정보는 출력하거나 저장하지 않았다.

## 비교 기준 오류

origin/feat/leewon(59802be)의 abc_fusion_experiment.py와 ABC_EXPERIMENT.md를 확인했다. ABC B는 우리 B와 다른 모델이다.

| 항목 | ABC B 기본 설정 | 우리 게이트 비교 |
|---|---|---|
| 조건·경과시간 | 입력 제외 | 정적 조건은 head, 경과시간은 query와 gate |
| 이미지 | 128 | 96 |
| attention | 단일 scaled-dot readout + residual FFN | 4-head MultiheadAttention |
| 가스 | 비선형 인코더, 결측 토큰 제외 | 선형 값+ID, 결측 표시를 토큰 입력으로 사용 |
| 전처리 | 원 수치 표준화 | 가스·시간·용량 signed log1p 후 표준화 |
| 손실 | inverse-sqrt 클래스 가중 CE | 일반 CE |
| 선택 | Train 내부 fit/dev, dev 최고 | 전체 Train 학습, Validation 최고 |
| 기본 학습 | 15epoch, batch64, weight_decay=1e-4 | 20epoch, batch32, weight_decay=1e-3 |
| 제출 | 기본 3seed 확률 평균 | 최고 Validation 단일 seed |

이는 저장소 코드 기본 설정 비교이며, 0.91 제출 파일이 실제로 어떤 명령과 checkpoint로 생성됐는지는 추가 확인이 필요하다. 따라서 0.91 vs 0.87을 게이트 유무만의 효과로 해석할 수 없다.

## 게이트 분포

| 모델·경로 | Validation 평균±표준편차 | Test 평균±표준편차 |
|---|---|---|
| 양쪽 게이트·가스 | 0.6596±0.1405 | 0.6768±0.1394 |
| 양쪽 게이트·이미지 | 0.7860±0.0951 | 0.7609±0.1010 |
| 이미지 단독 게이트 | 0.7829±0.1024 | 0.7373±0.1201 |

활성 게이트에서 0.1 미만은 없었다. 0.9 초과는 이미지에서 약3~5%, 가스에서0%. 0/1 포화 붕괴는 관찰되지 않았다.

이미지 단독 게이트의 평균은 Validation 0~60초0.4995, 180~600초0.7301, 1800초 이상0.8271로 달랐다. Test도 같은 방향이었다. 시간·센서·클래스·실험 구성의 상관이 섞여 있으므로 시간 직접 의존이나 인과적 원인으로 단정하지 않는다.

## 특징 크기

Validation 평균 L2: 양쪽 게이트의 가스11.2964→7.4918, 이미지13.5737→10.9533. 이미지 단독 게이트10.9217→8.9115. 실제 특징 감쇠는 관찰되지만 head가 이를 보상할 수 있으므로 중요도 또는 성능 저하의 증거는 아니다.

## 같은 checkpoint에서 gate=1로 개입

| 양쪽 게이트 모델 | Validation Macro F1 |
|---|---|
| 정상 | 0.709323 |
| 이미지 게이트 우회 | 0.715060 |
| 가스 게이트 우회 | 0.666764 |
| 양쪽 우회 | 0.674836 |

이미지 게이트 우회는 +0.574%p, 가스 게이트 우회는 -4.256%p였다. Test 예측 변경 비율은 각각1.07%,2.81%. Test 정답이 없어 개선/악화 여부는 알 수 없다. 우회는 같은 gated checkpoint의 추론 개입이며 처음부터 학습한 B/가스 단독 모델과 같지 않다. 이를 보고 Validation에 맞춰 우회를 선택하면 추가 선택 편향이 생긴다.

이미지 단독 모델의 CPU 재평가는0.704992였고 저장된 GPU 평가0.705464와0.000472 차이가 있었다. 코드 사본은 원본 image_gate.py와 동일하지만 플랫폼·배치 조건이 다르고 정확한 차이 원인은 아직 확인되지 않았다. 이 모델에서 이미지 gate 우회0.703479와의 작은 차이를 강한 증거로 쓰지 않는다.

## 판단

현재 낮은 공개 점수의 원인을 게이트로 확정할 수 없다. 먼저 ABC B에 같은 게이트만 추가하고 fit/dev, 입력, 이미지 크기, loss, seeds, ensemble까지 맞춰야 게이트의 추가 가치를 검증할 수 있다. 현재 진단은 이미지 게이트의 일관된 이점을 보여주지 않으며 가스 게이트와 역할이 다름을 시사한다. 공개 점수에 맞춘 반복 선택이나 Test 분포를 이용한 파라미터 조정은 하지 않는다.
