# 전압·가스 조건별 시계열 보정 비교와 선택 결과

## 실제 실행한 비교

원래 ABC B의 3-seed 평균을 고정했다. 기존 두 스테이지 S1은 fold 재학습한 별도 모델이므로 이번 기준 B와 혼동하지 않는다.

- 입력 비교 3개: 전체 센서, 보정기에 새로 들어가는 가스 정보 제외, 보정기에 새로 들어가는 전압 정보 제외. 각각 동일한 8epoch.
- 집중 학습 3개: 가스 0 행만, 급락 후 60초 구간만, 두 조건 합집합 행만 손실을 계산. 각각 동일한 24epoch. 입력 시퀀스와 과거 문맥은 유지한다.
- 각 모델을 전체/전압 현재/전압 최근60초/가스 0/교집합/현재 합집합/60초 합집합의 7개 범위에 적용하고, 보정 강도 0.5와 1.0 비교.
- 총 6개 학습 모델, 84개 적용 조합. 새 모델은 단방향 GRU이며 GLU라고 부르지 않는다. 동일 실험의 현재·과거만 사용한다. 합성 테스트로 미래 제거 불변성과 선택적 적용을 확인했다.

가스 0은 압력을 제외한 10종 농도가 모두 유한한 정확한 0인 조건이다. 측정 끊김이라고 확정하지 않는다. 전압 급락/급등 임계값은 원래 fit 변화율 하위/상위 1%로만 계산했다. 시간 차이는 실제 초 단위를 쓴다.

## 최종 선택

합집합 구간에 집중해 학습한 보정기를 **현재 전압 급락·급락 직후 반등 또는 가스 0인 행에만** 적용한다. 그 외 행은 원래 B를 유지한다.

| 항목 | 기존 B | 선택 후보 |
|---|---:|---:|
| Train 내부 dev Macro F1 | 0.781521 | 0.811235 |
| Validation Macro F1 | 0.696346 | 0.699593 |
| E16의5→4 오류 | 542 | 536 |
| E16의5단계 정답 | 6 | 9 |

Validation에서 기존 오답13건을 정답으로, 기존 정답2건을 오답으로 바꿨다. E16의 전체5단계590건 중 추가 정답은3건에 불과하므로 핵심 실패가 해결됐다는 주장은 하지 않는다.

선택 기준은 이상 조건에만 적용, dev가 기준 이상, Validation이 기준 이상, 고친 건수가 망친 건수보다 많음, 3/4/6단계 F1 손실0.03 이내를 통과한 후보 중 dev 최고다. 전체 적용 후보는 최종 후보에서 제외했다. 이 판단은 Test를 읽기 전에 완료했다.

Validation을 이미 여러 번 사용한 탐색 결과라 독립적인 최종 성능 증거가 아니다. 원래 dev도 ABC checkpoint 선택에 사용됐다. 보정 학습에 쓰는 B의 fit 확률은 in-sample이어서, 완전한 nested OOF 평가가 아니라는 한계가 있다. train_cv_f1이라는 이름으로 보고하지 않는다.

## 전압과 가스 중 무엇이 중요한가

### 보정할 구간의 비교

| 학습·적용 조건 | dev F1 | Validation F1 | 고친 수 | 망친 수 |
|---|---:|---:|---:|---:|
| 기존 B | 0.781521 | 0.696346 | 0 | 0 |
| 전압 최근60초 집중 학습·같은 구간 적용 | 0.790679 | 0.706356 | 27 | 4 |
| 가스 0 집중 학습·같은 구간 적용 | 0.800861 | 0.696278 | 1 | 2 |
| 합집합 집중 학습·현재 합집합 적용(최종) | 0.811235 | 0.699593 | 13 | 2 |

이 실험에서는 전압 변화 구간에 대한 보정의 Validation 이득이 더 뚜렷했다. 가스 0 보정은 dev 개선이 Validation으로 재현되지 않았다. dev의 모달리티/상태 분포에 의존할 가능성이 있으며, 가스 0이 곧 잘못 측정된 값이라는 증거는 아니다.

### 새 보정 입력의 제거 비교

같은8epoch와 전체 적용 기준으로 전체 입력 Validation0.719549, 새 가스 입력 제외0.722579, 새 전압 입력 제외0.716667이었다. 새 전압 정보를 제거할 때 약0.29%p 낮아졌고, 새 가스를 제거할 때 약0.30%p 높아졌다. 한 seed의 작은 차이므로 절대적 중요도나 물리적 인과를 뜻하지 않는다.

또한 Stage1 B 확률에는 이미 전압·가스 정보가 담겨 있다. 제거 실험은 보정기 추가 입력의 가치만 측정하며 시스템 전체에서 해당 모달리티를 제거한 실험이 아니다. 전압 조건으로 적용 대상을 고르는 정보도 별도로 남아 있다.

## 제출 파일

`submission_B_event_temporal_selected.csv`: 공식 양식의 sample_id,label 두 열, 3,451행. ID 집합·순서·label1~6 정수를 검사했다. Test에서 적용 가능한98행 중 최종 label은 기존 B 대비5행 바뀌었다. 조건 밖 변경은0행이다. 5행의 정답 여부와 공개 점수는 알 수 없고, 공개 사이트 업로드는 하지 않았다.

`selected_correction.pt`에는 보정 가중치·정규화·전압 임계값이 있다. 원래 ABC B 체크포인트와 현재·과거 센서 입력을 함께 사용해야 재현할 수 있다. 원본/행별 예측은 진단 보고서에 포함하지 않았다.

84개 전체 집계는 all_candidates.csv, 정확한 선택과 검증 정보는 selection.json에 있다. source_snapshot.py와finalize_snapshot.py는 실제 구현 사본이다. 기존 모델·결과는 덮어쓰지 않았다.
