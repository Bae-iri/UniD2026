# 하위 경계(2↔3, 3↔4) 보정

최종 모델(B + t1 45°C + 5→6 + 6→5, `final_submit/submission_rule1_56_65_past.csv`)이 손대지 않은 하위 경계에 보정을 더했다.

- **보정 후보:** 2→3, 3→2, 3→4, 4→3. 각 보정은 원래 기준 예측(B + t1)이 source인 행만 판단한다.
- **입력:** 현재까지의 관측만 쓴다. targeted_rule1의 센서 이력 특징(관측 개수 특징 제외)에 다음을 더했다.
  - 지금까지의 최고 전압 대비 현재 전압 비율, 최저/최고 비율, 강하 폭
  - t1·t2 누적 최대, t1이 45°C를 넘은 뒤 경과 시간, 전압이 최고 대비 95%·90% 아래로 내려간 뒤 경과 시간
  - B의 p2·p3·p4, 최근 60초 평균, B가 3·4단계에 처음 도달한 뒤 경과 시간
  - 특징 prefix 검증: 불일치 0
- **모델·기준값:** targeted_rule1과 같다(얕은 HGB, 학습 실험 3-fold로 0.5/0.7/0.9 중 자동 선택, 통과 조건 미달이면 끔).

## 채택 규칙 (결과 보기 전 고정)

보정 하나를 최종 모델에 더했을 때 다음 두 조건을 모두 만족하면 남긴다.
1. 개발 OOF 이득이 4개 간격 모두에서 0보다 크다.
2. 배터리 조합 통째 제외 평균 이득이 5s와 10/15s 모두에서 0보다 크다.

결과: 3→4와 4→3이 남았다. 2→3은 280Ah를 통째로 뺐을 때 −4.8점이라 탈락했다.

- 기준값은 학습 12번 모두 0.5였다. 3→4는 절반 가까이 꺼졌고(1.01), train 78 최종 학습에서도 꺼졌다.

## 주의: 이득 크기

- 검증용으로 다시 학습한 B(개발 77실험)는 실제 3을 4로 판정한 행이 412행이다.
- 제출에 쓰는 B 표현(targeted_rule1 OOF, train 78)에서는 83행뿐이다. 그래서 train 내부 3-fold 이득은 +0.24점에 그친다.
- 제출과 같은 조건(train 78 학습, 원본 B)으로 validation 19실험을 보면 다음과 같다.
  - +0.81점, E_e5bc 제외 +1.89점
  - 4개 간격 모두 +0.6~0.8점
  - 고친 행 92, 망친 행 0, 개선 실험 3 / 악화 실험 0
  - 다만 바뀐 행이 3개 실험에 몰려 있다.
- fold B 확률로 보면 3행만 바뀌어 +0.03점이다.
